# Spec Delta

## Purpose

为用户提供简洁、可靠的自然语言个人助手，并在任务需要时调用合适的工具完成代码、技能、外部系统和实时信息相关请求。

## ADDED Requirements

### Requirement: 自然语言对话
系统 SHALL 接受用户的自然语言请求，并以简洁、清晰且与请求相关的语言回答。

#### Scenario: 通用问题回答
- **WHEN** 用户提出无需外部工具的事实解释或一般性问题
- **THEN** 系统直接返回与问题相关的简洁回答

### Requirement: 按任务选择工具
系统 SHALL 根据任务需要选择可用的代码执行、Skills、MCP 或联网搜索工具，不得在未调用工具时虚构工具执行结果。

#### Scenario: 代码任务
- **WHEN** 用户请求需要通过代码沙箱完成的计算或代码执行任务
- **THEN** 系统调用代码沙箱并依据实际执行结果回答

#### Scenario: Skills 任务
- **WHEN** 用户请求通过指定 Skill 完成任务
- **THEN** 系统调用对应的 Skills 能力并返回实际处理结果

#### Scenario: 实时信息查询
- **WHEN** 用户询问最新新闻、天气或其他需要联网核实的信息
- **THEN** 系统使用联网搜索获取信息，并基于检索结果回答

#### Scenario: 外部 MCP 任务
- **WHEN** 用户请求需要外部 MCP 工具完成且路由可用
- **THEN** 系统通过 MCP 路由调用相应工具

### Requirement: 工具不可用时保持核心对话
当一个或多个可选工具不可用时，系统 SHALL 保持不依赖这些工具的核心对话能力，并向用户说明受影响的能力。

#### Scenario: MCP 路由不可用
- **WHEN** MCP 路由未配置或加载失败且用户继续一般对话
- **THEN** 系统正常处理一般对话，且仅限制需要 MCP 的请求

#### Scenario: 工具执行失败
- **WHEN** 所选工具返回错误或执行异常
- **THEN** 系统向用户返回可理解的失败说明，不声称任务已经成功
