# Spec Delta

## Purpose

为个人助手提供会话内连续上下文和可选的跨会话长期记忆，使用户偏好与重要信息能够在明确配置的存储中持久化。

## ADDED Requirements

### Requirement: 会话内短期记忆
系统 SHALL 在同一会话中保留可用于后续回答的上下文，并按用户和会话隔离短期记忆。

#### Scenario: 连续对话
- **WHEN** 用户在同一会话中先提供背景信息再提出相关问题
- **THEN** 系统能够利用该会话中的背景信息回答

#### Scenario: 会话隔离
- **WHEN** 用户切换到另一个独立会话
- **THEN** 系统不得把原会话的短期上下文当作新会话的已有信息

### Requirement: 长期记忆持久化
长期记忆存储已配置时，系统 SHALL 将会话中的用户偏好和重要信息持久化，以支持后续会话使用。

#### Scenario: 保存用户偏好
- **WHEN** 长期记忆已配置且用户明确表达需要记住的偏好或重要信息
- **THEN** 系统将该信息写入长期记忆，并可在后续会话中检索使用

### Requirement: 长期记忆可选降级
长期记忆存储未配置时，系统 SHALL 自动禁用长期记忆读写，同时保持短期记忆和核心对话可用。

#### Scenario: 未配置长期记忆
- **WHEN** 长期记忆配置缺失且用户发起一般对话
- **THEN** 系统正常回答，并明确提示长期记忆能力不可用

#### Scenario: 长期记忆写入失败
- **WHEN** 长期记忆后端在持久化会话时发生错误
- **THEN** 系统报告记忆保存失败，不得向用户确认信息已经持久保存
